# ☁️ Interactive Weather & Packing Planner

A vanilla HTML/CSS/JavaScript app that shows current weather, a 3-day forecast, and a smart, rules-based packing checklist for any city — with a UI that shifts its color theme to match the sky outside.

No frameworks, no build step. Open `index.html` and it runs.

---

## Overview

Search a city (or share your location) and get:

- Full current conditions — temperature, feels-like, humidity, wind, pressure, visibility
- A 3-day forecast
- A packing checklist generated by a small rules engine, not a wall of `if/else`
- A UI theme that shifts between sun / rain / snow / clouds / storm / mist palettes, driven entirely by 4 CSS variables
- °C / °F toggle that never re-calls the API
- Last 5 searches saved locally and re-searchable with one click

## Features

- 🔍 **Search on demand** — fetches only on button click or <kbd>Enter</kbd>, never while typing
- 📍 **Geolocation** — "Use My Location" with graceful handling of denied permissions
- 🎒 **Rules-based packing engine** — an array of `{ test, items }` rules evaluated against the day's weather
- 🎨 **Dynamic theming** — `--bg-color`, `--accent-color`, `--card-bg`, `--text-color` swapped from JS, no per-weather CSS classes
- 🌗 **Manual dark/light toggle** layered independently on top of the weather theme
- 🕓 **Live clock**, keyboard shortcut (<kbd>/</kbd> to focus search), animated rain/snow/sun-ray background
- 🗂️ **Search history** in `localStorage`, newest first, capped at 5
- ⏳ **Loading & error states** — spinner, disabled button, inline error banner; the app never throws to a blank screen
- ♿ **Accessible** — semantic landmarks, ARIA labels/roles, visible focus states, `prefers-reduced-motion` respected
- 📱 **Responsive** — tested down to 375px and up through 1440px

## Installation

1. Clone or download this folder.
2. Get a free API key (see below) and paste it into `script.js`.
3. Open `index.html` directly in a browser, or serve it with any static server (e.g. VS Code "Live Server").

No `npm install` required — there are no dependencies.



## Technologies

- HTML5 (semantic elements, ARIA)
- CSS3 (custom properties, `backdrop-filter`, grid, `color-mix`)
- Vanilla JavaScript (ES6+: `async/await`, destructuring, arrow functions, array methods)
- [OpenWeatherMap](https://openweathermap.org/api) Current Weather & 5-day Forecast APIs
